SUPORTELAB – UC11 | Guia do Estudante

Site estático em HTML, CSS e JavaScript puro.

Como abrir:
1. Extraia o arquivo ZIP.
2. Abra index.html no navegador.
3. Para publicar, envie index.html, style.css e script.js à raiz de um repositório GitHub Pages.

Não precisa de servidor, login, banco de dados ou build.
A fonte Google Fonts é opcional; sem internet, o site usa fontes locais alternativas.

Base: PTD da UC11, turma 2025.07.186, e calendário oficial enviado pelo instrutor.
Datas de aulas e atividades assíncronas ajustadas segundo as orientações posteriores do instrutor.
Eventos especiais: 02/11 (Finados), 24/11 (PI), 30/11 (dia sem aula informado).
Nota: Proclamação da República é oficialmente em 15/11; não foi atribuída essa denominação ao dia 30/11.
