# Aulas futuras

Todas as aulas ficam nesta pasta. Os endereços antigos (`/aula-1.html`, `/aula-assincrona-2.html` etc.) redirecionam com HTTP 308 via `vercel.json`. Novas aulas devem ser criadas nesta pasta como `aula-07.html`, `aula-08.html` etc.

## Integração ao catálogo

1. Criar e testar a página nesta pasta.
2. Adicionar o caminho relativo (por exemplo, `"lessons/aula-07.html"`) ao objeto `lessonFiles` em `script.js`.
3. Atualizar o calendário e a documentação da turma.
4. Verificar os caminhos de ativos da pasta (`../assets/...` e `../index.html`), o acesso no domínio Vercel, a impressão e a publicação.

Não mover nem renomear aulas já publicadas sem manter redirecionamentos para os links existentes.
